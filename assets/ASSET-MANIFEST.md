# Hero asset manifest

## `santuario-papel.webp`

- Purpose: responsive architectural hero for the wedding-padrinos invitation.
- Format and size: WebP, 1400 x 933 px (3:2 landscape), optimized for web delivery.
- Direction: original paper-cut bas-relief inspired by the Santuario del Señor de La Piedad, with warm ivory architecture, a powder-blue paper sky, blush-peach and dusty-sage foreground layers, and soft dawn light.
- Generation: OpenAI built-in ImageGen, using the approved `concept-c-editorial-procession.png` only as a style and visual-world reference.
- Prompt summary: place the dome and bell tower in the center-right; preserve generous clean negative space at left and upper-left; retain recognizable architectural details inside a mobile-safe central crop; use tactile handmade-paper texture and restrained relief shadows; exclude all people, rings, UI, text, labels, buttons, logos, invitation panels, and watermarks.
- Desktop crop: use the full 3:2 frame or anchor `center right`; the left third is intentionally quiet for live semantic copy.
- Mobile crop: use a centered or approximately `62% center` focal position. The dome, lantern, cross, and bell tower remain readable in a portrait cover crop; overlay copy should stay in the upper-left/sky area or in a separate HTML panel.
- Accessibility: the image contains no essential written information. Treat it as decorative when the adjacent HTML already names the place and occasion.
- Integrity: see the current repository checksum for the optimized delivery asset.
